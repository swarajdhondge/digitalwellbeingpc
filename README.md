## Features

- **Screen time:** today, this week and past weeks. Pauses after 5 minutes away unless you're watching or listening.
- **App usage:** top apps by time, with app switches and average focus.
- **App limits:** a daily allowance or off-limits hours per app. Pulse reminds you as often as you choose, or minimizes the app.
- **Focus sessions:** 15 to 90 minutes or custom. Warn mode nudges you; Block mode minimizes distractions.
- **Breaks and wind down:** 20-20-20 eye-break reminders and quiet hours with a soft screen glow.
- **Hearing protection:** estimates listening level from system volume and flags time above 75 dB. Never records audio.
- **Goals and insights:** a daily screen-time goal and a weekly report with week-over-week trends.
- **Command line:** `pulse today`, `pulse week` and `pulse apps` in any terminal.
- **Your data:** CSV export, backup and restore, delete any date range.
- **Your language:** English plus 13 translations\*, following Windows or chosen in Settings.

## Install

<a href="https://apps.microsoft.com/detail/9ND5GNMBQVQ7">
  <img src="https://get.microsoft.com/images/en-us%20dark.svg" alt="Get Pulse from the Microsoft Store" height="52"/>
</a>

The [Microsoft Store](https://apps.microsoft.com/detail/9ND5GNMBQVQ7) version is signed by Microsoft and updates itself. Or download `Setup.exe` from the [latest release](https://github.com/swarajdhondge/digitalwellbeingpc/releases): no admin rights needed, .NET included, automatic updates.

> [!NOTE]
> `Setup.exe` isn't code-signed yet, so Windows may say **"Windows protected your PC"** the first time. Click **More info → Run anyway**, or use the Store version. Each release includes `SHA256SUMS.txt` to verify the download.

## Command line

Both installers add a `pulse` command. Open a new terminal:

```text
pulse today    today's screen time and top apps
pulse week     this week, compared with last week
pulse apps     top apps (--week, -n 5)
pulse start    start Pulse in the background (pulse stop to quit)
```

`pulse help` lists everything. It reads what Pulse records, in the app's language.

## Build from source

```bash
git clone https://github.com/swarajdhondge/digitalwellbeingpc.git
cd digitalwellbeingpc
dotnet run --project digital-wellbeing-app
```

Needs the [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) and Windows 10 or 11.
